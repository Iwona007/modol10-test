Zadanie: Z1-01.01 - Stwórz Context File dla własnego projektu
Wybierz jeden ze swoich projektów (lub sklonuj dowolne publiczne repozytorium) i stwórz context file od zera.

Wymagania minimalne:
Sekcja Code Style z minimum 5 konkretnymi regułami
Sekcja Project Structure z opisem głównych katalogów
Sekcja Workflow z komendami do testów, budowania i sprawdzania typów
Sekcja Constraints z minimum 3 ograniczeniami

Bonus: Jeśli pracujesz z Cursor - stwórz dodatkowy plik w katalogu .cursor/rules/. Porównaj regułę dołączaną przez globs z podkatalogowym CLAUDE.md, który Claude Code ładuje przy odczycie pliku w jego zakresie.

Commituj context file do repozytorium.
